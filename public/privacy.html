Trip Planner 隱私權政策

最後更新日期：2026 年 11 月 12 日

歡迎使用 Trip Planner（以下簡稱「本應用程式」）。我們非常重視您的個人隱私與資料安全，本隱私權政策旨在說明我們如何收集、使用、儲存及保護您的資訊。

一、我們收集的資訊

  • Google 帳戶基本資料：當您選擇透過 Google 登入時，我們僅讀取您的基本公開檔案（名稱、電子郵件地址及個人頭像），用於識別您的使用者身分並在群組協作行程中顯示成員資訊。
  • Google 雲端硬碟授權（drive.file，選用）：僅當您主動使用「透過 Google Drive 同步自訂參考圖」功能時，本應用程式才會請求非敏感權限 https://www.googleapis.com/auth/drive.file。本應用程式僅能存取並管理由本應用程式為該功能建立的圖片檔案，絕不會讀取、列出或修改您雲端硬碟中的其他私人檔案。
  • 行程與景點資料：您建立或規劃的聖地巡禮景點、每日時程、個人標籤及拍照編輯紀錄。
  • 相機與檔案權限：本應用程式之相機疊圖與照片編輯功能僅於本機端執行，未經您的明確分享或同步操作，個人照片絕不會自動上傳至雲端。

二、資訊之儲存與使用方式

  • 本地優先（Local-First）：您的私人收藏庫、景點備註及巡禮照片預設儲存於您的本機裝置 SQLite 資料庫中。
  • 雲端雙向同步與圖片分享：僅當您明確開啟「群組分享行程」或透過邀請碼加入共用行程時，該行程之景點排程資料方會透過 Google Firebase 進行同步；若您主動將自訂參考圖上傳至自己的 Google Drive 以分享給行程成員，系統會為該張圖片建立「知道連結的任何人皆可檢視」（anyone with the link can view）的唯讀連結並同步至該共用行程。
  • Google API 資料使用揭露（Limited Use）：本應用程式對任何透過 Google API 取得之資訊的使用與傳輸，均嚴格遵守 Google API Services User Data Policy（包含 Limited Use 限制使用規範）。
  • 絕不出售資料：我們絕不會將您的個人資訊販售、出租、用於廣告投放或轉讓給任何第三方。

三、第三方服務提供商

本應用程式使用受信任的第三方服務以維持基本營運：

  • Google Firebase：用於使用者驗證（Authentication）與行程雲端資料庫（Firestore）。
  • Bangumi 與 Anitabi：提供公開的動畫資料與聖地座標資訊檢索。
  • OpenStreetMap：搜尋地點時，您輸入的文字會傳送至 OpenStreetMap 的 Nominatim 服務以查詢座標；地圖畫面的圖磚亦由 OpenStreetMap 提供。
  • Google 地圖：當您貼上 Google 地圖短網址時，本應用程式會開啟該網址以讀取其中的座標。
  • GitHub：首次使用去背功能時，會從 GitHub 下載去背模型檔，此請求不包含您的個人資料。

四、資料刪除與權利行使

您隨時可於應用程式內刪除行程資料或登出帳號。如欲請求徹底刪除您在雲端的帳戶相關資料，請透過下方聯絡信箱與我們聯繫，我們將於收到請求後儘速處理。
